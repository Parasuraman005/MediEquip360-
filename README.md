# MediEquip360

**Smarter Medical Equipment. Better Healthcare.**

MediEquip360 is an online medical equipment procurement platform designed to help hospitals, clinics, and healthcare professionals explore medical devices and healthcare equipment. It provides a user-friendly platform for discovering products, submitting enquiries, requesting quotes, and raising product support complaints.

## Features

- **Product Catalog** – Browse medical equipment across multiple categories.
- **Product Details** – Explore product descriptions and specifications.
- **Product Enquiries** – Submit enquiries about medical equipment.
- **Request a Quote** – Request pricing information for products.
- **Customer Support** – Submit product complaints and support requests.
- **Form Validation** – Input validation with success and error notifications.
- **Responsive Design** – Optimized for desktop, tablet, and mobile.
- **SEO Optimization** – Page-specific metadata and Open Graph tags.
- **Error Handling** – Custom 404 and 500 error pages.
- **Analytics Integration** – UTM campaign tracking and important event tracking.

## Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Vite
- React Router
